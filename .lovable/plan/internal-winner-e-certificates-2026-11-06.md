# Internal winner e-certificates

## Scope
- Use the uploaded certificate template for internal competition prize winners.
- Add individual PDF download actions and print-ready certificates for hard copies.
- Preserve current-year filtering, winner selection, and existing internal-only access.

## Implementation
- Keep generation in the existing certificates screen using the installed PDF library.
- Store the uploaded template through the project asset flow and use it as the PDF background.
- Add per-winner download/print actions and a selected-winners print action.

## Verification
- Check PDF layout and text placement against the supplied template.
- Verify the certificates screen and generated download/print actions in the preview.
